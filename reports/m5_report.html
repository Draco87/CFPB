RAG evaluation

Answer-key retrieval tests and LLM-as-judge faithfulness.

What Module 5 measures

Two questions, both answered without needing legal expertise: (1) does the search find the right rules - checked against an answer key; (2) do the drafts say only what those rules say - checked by a larger LLM acting as a judge, which is itself spot-checked by a human.

1. Does the search find the right rules?

34 realistic complaints with a known correct rule (the answer key). For each search setup we check whether that rule is among the 5 passages the LLM would be given.

The setup used in Module 4 finds a correct rule for 29/34 complaints (MRR 0.66: the correct rule is usually 1st or 2nd).

Best setup: Hybrid + rerank + rewrite (final) (29/34).

2. Do the drafts stick to the rules they were given? (faithfulness)

A larger model (Qwen2.5-7B-Instruct) acted as the judge. For every draft it listed each statement about what a rule requires, and marked it supported only if a retrieved passage clearly says it.

Faithfulness = supported statements / all statements. In the final setup, 47% of rule statements are supported; 18 of 26 drafts contain at least one unsupported statement.

Compared with Version 1, faithfulness changed from 51% to 47% (-5 points).

3. Can we trust the judge?

Created m5_judge_check.csv with 20 statements the judge ruled on. Open it in Excel, read each statement and the passages, and write yes (a passage says this) or no in your_verdict. Save and run this script again to see how often you and the judge agree.
