Fairness check - risk model

200,000 test complaints (2025-26); groups from the CFPB 'tags' field.

What this checks

Module 3's model flags complaints likely to end with the company paying. If agents use it to decide which complaints to look at first, it should not quietly overlook some groups.

The data only tells us two groups: complaints tagged Older American and Servicemember. There is no gender, race or income, so this cannot rule out unfairness to groups we cannot see.

1. The numbers per group

Ranking (ROC-AUC): 0.5 = random, 1 = perfect. Unlike PR-AUC it does not depend on how common payouts are, so it is the fair way to compare groups with different payout rates.

Payout cases found in top 10%: if agents review the riskiest 10% of all complaints, how many of this group's real payout cases they would see. Similar values = equal opportunity.

Expected from its products: the payout rate the group would have if it paid out like everyone else for the same products. Close to the actual rate = the difference is about what people complain about, not who complains.

2. Are the gaps real or chance?

For each group we resampled the data 500 times and recomputed the gap to everyone else. The range shown holds the true gap 95% of the time; if it includes 0, the gap may be chance.
